# Library Management System (MySQL)

## Project Description
This project is a database system for managing library operations including books, students, and issue records.

## Technologies Used
- MySQL
- Lucidchart (ERD/DFD)

## Features
- Manage books
- Manage students
- Issue books
- Track returns

## How to Run
1. Open MySQL Workbench
2. Run schema.sql
3. Run inserts.sql
4. Run queries.sql
5. Or run database project.sql
